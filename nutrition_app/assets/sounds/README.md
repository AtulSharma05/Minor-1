# Metronome Sound Files

This folder contains audio files for the metronome feature.

## Sound Files Needed:

### 1. tick.wav
- Duration: ~100ms
- Frequency: ~600Hz
- Use: Regular beats (2nd, 3rd, 4th beats of measure)

### 2. tock.wav  
- Duration: ~120ms
- Frequency: ~800Hz
- Use: Accent beats (1st beat of measure)

## How to Generate:

You can generate these sounds using:
1. Online tone generators (e.g., tone-generator.com)
2. Audio editing software (Audacity, GarageBand)
3. Programming libraries for audio generation

Currently using system sounds (SystemSound.play) as a fallback until actual audio files are provided.
